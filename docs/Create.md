# Crear contenido

Aqui podras crear y modificar contenido con una interfaz grafica

## Lenguaje

Aqui podras elegir el lenguaje para modificarlo o crear uno nuevo. Una vez elegido iras a modulos

## Modulos

Aqui podras elegir crear o modificar un modulo. Luego iras a niveles

## Levels

Aqui podras crear o modificar niveles, hay dos tipos: de informacion y de actividad.

Los de informacion son textos y ejemplos.
Los de actividad son un texto con el enunciado y una pantalla dividida con el resultado (a la derecha) y la 'consola' (a la izquierda).

Podras marcar un nivel para que sea de pago. En ese caso el nivel se colocara directamente al final (sera el ultimo nivel).

Tambien podras modificar el orden de los niveles (podras intarcambiar el nivel 2 por el 4, entonces el nivel 2 pasara a ser el 4 y viceversa).

## Niveles

Aqui se mostran todos los niveles del modulo. Los niveles tiene 4 vistas: Completado, actual, bloqueado, vip.

El completado sera de color claro y con un tick encima
El actual sera de color claro
El bloqueado sera de color oscuro y tendra un candado
El vip tendra un borde colorido y podra ser completado, actual o bloqueado.

## Vip

Si pulsas sobre un nivel vip te saldra una opcion para comprar el vip de ese lenguaje.

## Progreso niveles

Es un progreso lineal, para llegar al nivel 5 tienes que haber completado el nivel 4.

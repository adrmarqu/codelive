# Header

El header estara formado por el logo y un contenedor

El logo te redirigira al home

El contenedor dependera del rol del usuario:

(modo LD) -> Modo claro y modo oscuro

## Invitado

El contenedor tendra dos enlaces, uno al login y el otro al signin, asi como un boton para el modo LD

## Usuario

El contenedor tendra un desplegable (que sera el nombre del usuario) que tendra:

- Perfil
- Progreso
- Ranking
- Logout
- LD

## Editor

El contenedor tendra un desplegable (que sera el nombre del usuario) que tendra:

- Perfil
- Progreso
- Ranking
- Crear contenido
- Logout
- LD

## Admin

El contenedor tendra un desplegable (que sera el nombre del usuario) que tendra:

- Login
- Signin
- Perfil
- Progreso
- Ranking
- Contacto
- Lista de usuarios
- Crear contenido
- Logout
- LD

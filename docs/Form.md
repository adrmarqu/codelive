# Form

Sera un formulario centrado

## Form auth

Formularios para conectar y registrar una cuenta

Solo accesible para invitados y el administrador

Si los usuarios o los editores entran, seran redirigidos al home

### Login

- Correo
- Contraseña
- Recordar usuario
- Contraseña olvidada

- Cancelar
- Enviar

### Signin

- Username
- Correo
- Contraseña
- Repetir contraseña
- Terminos y servicios

- Cancelar
- Enviar

Al cancelar te devuelve donde estabas
Al enviar te redirige al Home

## Form update

### User

- Nuevo usuario
- Contraseña

- Cancelar
- Enviar

### Email

- Nuevo email
- Contraseña

- Cancelar
- Enviar

### Pass

- Contraseña actual
- Nueva contraseña
- Repetir nueva contraseña

- Cancelar
- Enviar

### Recuperar password

- Nueva contraseña
- Repetir nueva contraseña

- Enviar

Al cancelar te devuelve donde estabas
Al enviar te redirige al Perfil
